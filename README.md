# 3학년 시간모의고사 일정 및 감독 통합 운영 시스템

2026학년도 고등학교 3학년 시간모의고사 일정 및 기존 시간표 연동형 감독 배정 웹사이트입니다.

## 📌 주요 특징
- **기존 시간표 1:1 연동**: 별도 감독 편성 없이 해당 교시 수업 교사 자동 배정
- **교시 분할 및 무감독 운영**: 80분/100분 시험을 50분(앞교시) + 10분(무감독) + 나머지(뒷교시)로 분할
- **자습 및 휴식 시간**: 2~3교시 사이 40분(10:10 ~ 10:50) 자습 및 휴식
- **요일별 종료 시각 분기**:
  - **월·수·금**: 15:30 한국사 종료 즉시 전 시험 종료 및 학급 종례
  - **화·목**: 16:30 탐구 2과목(각 30분) 완료 후 최종 종례
- **선생님별 맞춤 조회**: 내 감독 배정표 확인, 주간 감독 시간 통계, 원래 수업 시간표 비교 및 인쇄/복사 기능 제공
- **반별 게시용 시간표 & 실시간 시뮬레이터 지원**

## 🚀 GitHub Pages 배포 방법
1. 저장소(Repository) 상단 **Settings** 클릭
2. 좌측 메뉴에서 **Pages** 클릭
3. **Build and deployment** > **Branch**를 `main` (또는 `master`), 폴더를 `/ (root)`로 선택 후 **Save** 클릭
4. 약 1~2분 후 생성되는 웹사이트 링크(`https://<username>.github.io/<repo-name>/`)로 접속 가능합니다.
